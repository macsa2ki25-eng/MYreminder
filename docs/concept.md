# MYreminder 構想（たたき台 v0.1）

> まだ作り始める前の「構想」です。下の「相談したいこと」に答えてもらってから作り始めます。

---

## 1. 現状の整理

### これまでの方法が続かなかった理由

| 方法 | うまくいかなかった理由 | 根っこにある問題 |
| --- | --- | --- |
| カレンダー | 管理すること自体が負担 | **入力・整理を自分でやる必要がある** |
| 付箋 | いつの間にか景色になる | **ずっと見えているものは、慣れて見えなくなる** |
| Todoアプリ | 開くのが続かない | **自分から見に行く必要がある** |

### 分かったこと

- 「自分から見に行く」仕組みは続かない
- 「ずっと見えている」仕組みは慣れて無視してしまう
- → 必要なのは **「必要な瞬間に、向こうから割り込んでくる」** 仕組み

### 毎日の習慣になっているもの（これに相乗りする）

- 職場のパソコンを操作する（メイン）
- スマホを開く（仕事中は見ないこともあるので補助）

### 扱いたいもの

| 種類 | 例 | いつ思い出したいか |
| --- | --- | --- |
| 授業での用事 | 「2-1でプリントを配る」「この授業でこの話をする」 | その授業の前の休み時間 |
| 帰りのSTの用事 | 「帰りSTで保護者会の手紙を配る」 | 帰りSTの前 |
| 予定 | 「金曜15時 学年会」 | 予定の少し前 |
| 忘れないためのメモ | 「〇〇先生に鍵を返す」 | 今日のどこか／朝 |

---

## 2. 設計の3原則

1. **開かなくていい** — アプリを開く習慣はいらない。パソコンを使っていれば向こうから出てくる
2. **景色にならない** — 出しっぱなしにしない。「今」と「次」に関係あるものだけを、その瞬間に大きく出す
3. **続かなくても壊れない** — サボっても溜まらない。分類・日付・カテゴリを自分で選ばない。終わったものは勝手に消える

## 3. 使い方のイメージ

### 入力：一言書くだけ（分類はアプリがやる）

| 入力した文 | アプリの判断 |
| --- | --- |
| `2-1 プリント配る` | 時間割から「次の2-1の授業」を探して、そこにくっつける |
| `帰りST 保護者会の手紙` | 今日の帰りSTにくっつける |
| `金曜 15時 学年会` | 金曜15時の予定 |
| `田中先生に鍵返す` | 判断できない → 「今日のメモ」に入れる |

- 書き方のルールを覚えなくていいように、ゆるく判定します（迷ったら「メモ」）
- スマホからも同じように一言で入力（音声入力も可）

### 割り込み：必要な瞬間だけ、でかでか

| タイミング | 出てくるもの |
| --- | --- |
| 朝、パソコンを開いた時 | 今日の全部（授業ごと・帰りST・予定・メモ） |
| 各授業の前の休み時間 | 「次 3限 2-1：進路希望調査を配る」 |
| 帰りSTの5分前 | 「帰りSTで話すこと 2つ」 |
| 予定の10分前 | 「15:30 学年会」 |

画面イメージ：

```
┌──────────────────────────────────────────┐
│  10/2(金)        いま：休み時間                │
│                                          │
│  ▶ 次は 3限 2-1                            │
│                                          │
│     ・進路希望調査を配る                      │
│     ・小テストの範囲を伝える                   │
│                                          │
│ ──────────────────────────────────────── │
│  帰りST   保護者会の手紙                      │
│  予定     15:30 学年会                       │
│                                          │
│          [ ✓ やった ]   [ あとで ]            │
└──────────────────────────────────────────┘
```

### 自動で消える

| 種類 | 消え方 |
| --- | --- |
| 予定 | 時間が過ぎたら勝手に消える |
| 授業・帰りSTの用事 | その時間が終わったら「やった？」と1回だけ聞く → ✓で消える（✓しなかった時の扱いは要相談） |
| メモ | ✓で消える（放置した時の扱いは要相談） |

## 4. 技術的な実現方法（セキュリティとの相談）

職場PCでよくある制約：ソフトのインストール不可／拡張機能不可／設定変更不可／外部サービスへの業務データ保存NG

### 候補

| 案 | 中身 | 良い点 | 心配な点 |
| --- | --- | --- | --- |
| **A. ブラウザで動くWebアプリ** | Edge/Chromeで開くだけ。「アプリとしてインストール」できればPC起動時に自動で開く | インストール不要。PCでもスマホでも動く | 外部の置き場所が必要。データの保存先をどうするか |
| **B. 学校のGoogleアカウント上で動かす** | Googleスプレッドシート＋Apps Script。予定は自動でGoogleカレンダーへ | データが学校のアカウント内に閉じる。スマホ通知はカレンダーアプリが自動でやってくれる（カレンダーを自分で管理する必要はない） | 学校がGoogle Workspaceを使っている場合のみ |
| **C. 学校のMicrosoft 365上で動かす** | Teams / Outlook / To Do などと連携 | データが学校のアカウント内に閉じる | 学校がMicrosoft 365の場合。できることは要調査 |
| **D. HTMLファイル1つだけ** | PCの中だけで動く。ネット不要 | 一番安全。許可が要らない可能性が高い | スマホと連携できない |

### 「割り込み」の実現方法

ブラウザだけだと「勝手に画面の一番前に出てくる」ことは制限されています。そこで次を組み合わせる想定です。

1. **PCのログイン時に自動で開く**（スタートアップに登録 or ブラウザの起動ページに設定）
2. **時間になったらWindowsの通知を出す**（音つき・消すまで残る）
3. （許可されていれば）**Windowsのタスクスケジューラで、決まった時刻にウィンドウを前面に開く** → 本当の「割り込み」になる

### 注意：授業中の画面

授業でこのPCをテレビ・プロジェクタに映している場合、割り込みが生徒に見えてしまいます。
→ 「授業中は割り込まない」「休み時間だけ出す」「生徒の名前は書かない／伏せて表示」などの配慮が必要です。

## 5. 「作っても続かない気がする」への対策

- **最初から全部作らない。** まずは「朝PCを開いたら今日の分がでかでか出る」＋「一言入力」だけで1週間試す
- **続かなかったら、それはアプリ側の問題。** 「ここが面倒だった」を教えてもらって、アプリを自分に合わせて直す
- **サボっても大丈夫な設計。** 何日入力しなくても、溜まらず・壊れず・責めてこない

## 6. 相談したいこと

1. **端末**：「このパソコン」と「このタブレット」は同じ端末ですか？ Windows／Chromebook／iPad のどれですか？ ブラウザは Edge／Chrome のどちらを使っていますか？
2. **職場PCでできること**（分からなければ「分からない」でOK）
   - ソフトのインストール
   - ブラウザの起動ページ（ホームページ）の変更
   - Edge/Chromeの「このサイトをアプリとしてインストール」
   - タスクスケジューラ・スタートアップへの登録
3. **学校のアカウント**：Google（Gmail・Classroom）と Microsoft（Teams・Outlook）のどちらですか？ そのアカウントにスマホでログインしていますか（していいですか）？
4. **スマホ**：iPhone／Android？ 仕事のメモを個人のスマホに入れてもいい環境ですか？
5. **時間割**：校時表（何限が何時から何時か）と、自分の週の時間割（何曜何限にどのクラス）を一度だけ教えてもらえますか？ 担任をしていて、帰りのSTは毎日ありますか？
6. **やらなかった用事**：✓をつけずに時間が過ぎた用事はどうしますか？
   - (a) 次の同じクラスの授業に自動で繰り越す
   - (b) 1回確認して、無視したら消す
   - (c) 赤くなって残り続ける
7. **画面の映し出し**：授業中にこのPCをテレビ・プロジェクタに映すことはありますか？
8. **生徒の名前**：メモに生徒の名前などの個人情報を書くことはありそうですか？（データの保存先の選び方が変わります）
