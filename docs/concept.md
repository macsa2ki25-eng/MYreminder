## 1. 現状の整理

### これまでの方法が続かなかった理由

| 方法 | うまくいかなかった理由 | 根っこにある問題 |
| --- | --- | --- |
| カレンダー | 管理すること自体が負担 | **入力・整理を自分でやる必要がある** |
| 付箋 | いつの間にか景色になる | **ずっと見えているものは、慣れて見えなくなる** |
| Todoアプリ | 開くのが続かない | **自分から見に行く必要がある** |

→ 必要なのは **「必要な瞬間に、向こうから割り込んでくる」** 仕組み

### 扱いたいもの

| 種類 | 例 | いつ思い出したいか |
| --- | --- | --- |
| 授業での用事 | 「2-1でプリントを配る」「この授業でこの話をする」 | その授業の直前 |
| 帰りのSTの用事 | 「帰りSTで保護者会の手紙を配る」 | 帰りSTの直前 |
| 予定 | 「金曜15時 学年会」 | 予定の少し前 |
| 忘れないためのメモ | 「〇〇先生に鍵を返す」 | 一日のどこかで何回か |

## 3. 設計の3原則

1. **開かなくていい** — アプリを開く習慣はいらない。PCを使っていれば、時間になると向こうから出てくる
2. **景色にならない** — 出しっぱなしにしない。用事がある時だけ、その瞬間に大きく出す。用事がない時は何も出さない
3. **続かなくても壊れない** — 分類・日付を自分で選ばない。終わったものは消える。サボっても責めてこない

## 4. 全体の形

```
 ┌──────────── iPhone（補助・入力だけ） ────────────┐
 │ ホーム画面のボタン or Siri に一言                    │
 └──────────────┬──────────────────────┘
                │ 私用Googleの「受け渡しポスト」
                │ （PCが受け取ったらすぐ消す）
                ▼
 ┌──────────── 職場PC（メイン） ─────────────────┐
 │ 常駐アプリ（画面右下のタスクトレイにいる）             │
 │  ・一言入力 → 自動で振り分け                          │
 │  ・時間になったら画面の最前面に、でかでか              │
 │  ・データはPCの中だけに保存（生徒の名前があるため）     │
 └────────────────────────────────────┘
```

## 5. PCアプリの動き

### 入力：一言書くだけ

入力の入口は2つ：

- **キーボードのショートカット**（例：`Ctrl + Shift + Space`）
- **画面の端にある小さな「＋」ボタン**（タブレットでタッチ操作している時用）

| 入力した文 | アプリの判断 |
| --- | --- |
| `2-1 プリント配る` | 時間割から「次の2-1の授業」を探して、そこにくっつける |
| `3限 小テスト返す` | 今日の3限（もう過ぎていたら次の3限） |
| `帰りST 保護者会の手紙` | 今日の帰りST（もう過ぎていたら次の日） |
| `金曜 15時 学年会` | 金曜15時の予定 |
| `明日 鍵返す` | 明日のメモ |
| `田中先生に鍵返す` | 判断できない → 今日のメモ |

### 割り込み：用事がある時だけ、最前面にでかでか

| タイミング | 出てくるもの |
| --- | --- |
| 朝、その日はじめてPCを触った時（ロック解除・久しぶりの操作を検知） | 今日のまとめ（全部） |
| 授業の5分前（その授業に用事がある時だけ） | その授業の用事 |
| 昼休みの始め | メモ・午後の予定 |
| 帰りSTの5分前 | 帰りSTの用事・今日のやり残し |
| 予定の10分前 | その予定 |

画面イメージ（通常）：

```
┌──────────────────────────────────────────┐
│  10/2(金)  10:55                          │
│                                          │
│  ▶ 次は 3限 2-1                            │
│                                          │
│     ・進路希望調査を配る                      │
│     ・小テストの範囲を伝える                   │
│                                          │
│ ──────────────────────────────────────── │
│  🔴 やり残し  1限 2-3 課題回収               │
│                                          │
│     [ ✓ ぜんぶやった ]   [ 5分後にもう一度 ]     │
└──────────────────────────────────────────┘
```

### 目隠しモード（プロジェクタ接続中）

PCにプロジェクタ・テレビがつながっていることを検知したら、中身を伏せて出します。

```
┌──────────────────────────────┐
│  📌 3限の用事が 2件あります          │
│     （プロジェクタ接続中なので非表示）   │
│         [ タップして表示 ]          │
└──────────────────────────────┘
```

### 消え方

| 種類 | 消え方 |
| --- | --- |
| 予定 | 時間が過ぎたら勝手に消える |
| 授業・帰りSTの用事 | ✓で消える。✓しないまま時間が過ぎたら **赤くなって残り**、次の割り込みのたびに一番上に出る |
| メモ | ✓で消える。その日に✓しなかったら赤くなって残る |
| 赤が溜まりすぎた時 | 朝のまとめに「まとめて片付け」ボタンを出す（赤が景色にならないように） |

## 6. iPhone（補助）

### 通知（ステップ1で作成済み）

- 割り込みに3分さわらなかったら、iPhone に「📌 PCにリマインドがあります（3限の前）」と通知
- 中身は送らない。通知には無料の「ntfy」アプリを使う
- 学校のネットワークで ntfy が止められていた場合は、私用Gmailへのメールで代わりに通知する方法に切り替える

### 入力（ステップ2）

- ホーム画面のボタン（iPhoneの「ショートカット」アプリ）か Siri に一言 → PCに届く
- 届け方：私用Googleのスプレッドシートを「受け渡しポスト」として使い、**PCが受け取ったらすぐにGoogle側から消す**
- それでも一瞬Googleを通るので、**スマホから送る時は生徒の名前はイニシャルや番号で**書く運用をおすすめ
- スマホにリマインドを出す機能は、まずは作らない（PCで十分か試してから考える）
