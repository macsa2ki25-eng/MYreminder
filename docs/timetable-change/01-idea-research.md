# 時間割変更システム 調査メモ（1）いま使っている「イデアのAI時間割」

> 新しい時間割変更システムを考える前に、いま学校で使っている「イデアのAI時間割」（株式会社イデアシステム）を調べたメモです。

## 1. ひとことで言うと

**イデアは「年度はじめに1枚の時間割を完成させる」ためのソフトで、日々の変更はその上に後から足された機能。**

- 中心にあるのは「駒入れ」（授業を表に自動で入れていく機能）。ここは長年かけて強くしてきた
- 日々の変更も「同じ表の上で駒を動かす」やり方。**日付（10/14(火) の 3限）という考え方は本体にない**
- 臨時の時間割は「基本の時間割を **別の名前で保存** して直す」やり方（公式）

| 用語 | 意味 | 出どころ |

### 時間割の枠

- **1〜12日 × 1〜16時限** の範囲で自由に決められる（公式）
- つまり「月〜金」や「A週・B週」のような **くり返しの型** を1つ作るイメージ（推測）

### 決められる条件（主なもの）

| 種類 | 例 | 出どころ |
| --- | --- | --- |
| 全体 | 連続して置く・1日に置ける上限 など。条件の組み合わせを3つまで名前をつけて保存・切り替え | 公式 |
| 先生ごと | 1日の授業の上限／禁制／連続の制限／1日に最低n時間は空ける | 公式 |
| 先生ごと（2026で追加） | 午前の授業時間を制限／午後の授業時間を制限／1日の拘束時間（コマ数）を制限 | 公式 |
| 教室 | 同時に入れる数（収容数） | 公式 |

## 4. 作るための機能（駒入れ）

| 機能 | 内容 | 出どころ |
| --- | --- | --- |
| 自動の駒入れ | 最大21駒を玉突きで入れ替えながら置いていく（2008年に21駒交換まで対応） | 公式 |
| 新AIエンジン | それまであった「展開の数」の制限をなくし、5展開以上の選択授業も入れ替えの対象にした | 公式 |
| 学習駒入れ | 確定授業以外を全部はずして、くり返し試す。残り駒をなくすことを最優先 | 公式 |
| 試行方針 | 「速度優先・標準・深読み優先・熟考」の4段階。残りが多いうちは速く、残り数コマになったら深く | 公式 |
| 宣伝文句 | 「条件に矛盾がなければ、ほぼ全部残り駒ゼロで完成」 | 公式 |

### 駒が入らないときの公式の対処

- 「駒が入らない時にチェックする基本事項」として、**クラスの授業時数とオプション、先生の授業時数とオプション、教室の収容数を自分で確かめる** よう案内している（公式）
- 配置が偏るときは「試行方針を『標準』にして保存 → ソフトを終了・再起動 → 十分な試行時間で駒入れをやり直す」（公式）
- それでもだめなら、データをメールで送ってサポートに分析してもらう（公式）

→ **ソフト自身は「なぜ入らないのか」を教えてくれない**（推測。公式の対処がすべて「人が確かめる」「やり直す」「送って見てもらう」になっているため）

## 5. 変えるための機能（時間割変更）

| 機能 | 内容 | 出どころ |
| --- | --- | --- |
| AI手直し | AI一覧表（クラス・先生・教室の一覧）の上で、駒をドラッグ＆ドロップ・右クリックして直す | 公式 |
| 移動提案 | 駒をつかんで少し揺らすと、置ける時間に印（時間割マーク）が出る | 公式 |
| 振替提案 | 先生や教室の都合がつかなくなった授業を、条件を守ったまま別の授業と入れ替える案を出す。候補先をクリックすると **交換する駒の数が少ない順** に案が並び、「次提案」で1つずつ見ていく | 公式 |
| 提案のグラフィック表示 | 案を図で見て、目で確かめて選ぶ | 公式 |
| 持ち手変更・教室変更 | 先生の一覧で縦に動かすと担当の先生が変わる。教室の一覧で縦に動かすと教室が変わる | 公式 |
| 自習監督設定 | その授業の自習監督ができる先生を出す。担当しているクラスの先生を **緑（時間オーバーしない）・オレンジ（オーバーする）** で表示 | 公式 |

| 育休・出張・病欠 | AI手直しで持ち手の変更や振替をして、学校全体で矛盾のない変更をする（専用の機能というより、手直しの使い方として案内） | 公式 |

- 試験監督を「所属学年・受け持ちクラスに限る」「受け持ちではない先生に限る」「限らない」から選べる（公式）

## 8. 分析：なぜ「うまくいかない」のか（仮説）

いただいた3つの困りごとに、イデアの作りを当てはめてみました。**ほとんどが推測** なので、実際に使っている感覚と合っているか教えてください。

### ① 使いづらい

| 考えられる原因 | 確度 |
| --- | --- |
| 「作る」ための大きな一覧表の上で「変える」作業もする。駒を揺らす・右クリック・縦に動かすと意味が変わる、など操作を覚える必要がある | 公式の操作説明から推測 |
| 日付がない。「10/14(火) の3限」ではなく「火曜の3限の駒」を動かす。臨時の時間割は別名保存のファイルとして増えていく | 公式（別名保存）＋推測 |
| 毎年の版で機能が足されていくので、画面や設定が多い | 推測 |
| 変更係のPC（最大3台）でしか触れない。ほかの先生はビューワーか印刷を見るだけ | 公式 |

### ② 駒があてはめられない

| 考えられる原因 | 確度 |
| --- | --- |
| 自動の駒入れは「玉突きを試して、ある程度で切り上げる」方式。入らないとき、**本当に無理なのか、探しきれていないだけなのか** が区別できない。だから「試行方針を変える・再起動してやり直す」が対処になる | 公式の対処から推測 |
| **なぜ入らないかを言ってくれない**。何が邪魔をしているか（どの先生の禁制か、どの教室か）を人が探す | 公式の対処から推測 |
| 条件は基本的に「守る／守らない」の二択。「できれば避けたい」の度合いを細かく決めにくい | 推測 |

### ③ 機械的に出した変更ではうまくいかない

| 考えられる原因 | 確度 |
| --- | --- |
| 振替提案の並び順は **「交換する駒の数が少ない順」だけ**。条件さえ守っていれば、どれも同じ「正しい案」として出てくる | 公式 |
| 人が頭の中で気にしていることが、ソフトの判断に入っていない。たとえば… | 推測 |
| 　・同じ先生ばかり動かしていないか（今週もう3回目） | |
| 　・本人に頼みやすいか、了承をもらえるか | |
| 　・同じクラスで同じ科目が1日に2回にならないか、逆に何日も空かないか | |
| 　・テスト前・進度・展開授業でどちらかだけ進む | |
| 　・前に借りた授業を返す時期か | |
| 　・移動教室・体育館・特別教室の使い方 | |
| 「その日だけの事情」（出張・教室が使えない）を入れるには、時間割そのものの条件（禁制など）を変えることになる | 推測 |
| 変更が毎日積み重なるのに、**誰の授業を何回借りて、いつ返すか** の記録はソフトの外（年間実績は後から集計するだけ） | 推測 |

## 9. 新しいシステムで変えられそうなこと（たたき台）

まだ方向性だけです。下の「確認したいこと」の答えで変わります。

1. **作るのはイデア、変えるのは新システム**
   年度はじめの基本時間割はイデアで作り、CSV・Excel で取り出して新システムに読み込む。日々の変更だけに集中した道具にする。
2. **日付で考える**
   1年分のカレンダーに基本時間割を並べ、変更は「その日だけの差分」として記録する（誰が・なぜ・いつ返すか）。基本の時間割は汚さない。
3. **「答え」ではなく「候補と理由」を出す**
   候補ごとに「✓ 守れていること」「⚠ 気になること（○○先生は今週3回目、3-1の論表が同じ日に2回）」を並べ、最後は人が選ぶ。選んだ傾向を覚えて、次から並び順に反映する。
4. **入らないときは「なぜ」を言葉で**
   日々の変更は、年度はじめの作成よりずっと範囲が狭い（例：前後2週間・関係する先生とクラスだけ）。全部の組み合わせを調べきれる見込みが高く（要検証）、「どこにも入らない」と言い切ったうえで、「この時間は○○先生が学年会」「この条件を1つゆるめれば入る」と示せる。
5. **時数の貸し借りが、変更を決める画面で見える**
   「3-1 論表：今学期の予定40 → 実施見込み38（2不足）」のように、決める瞬間に分かる。
6. **連絡まで**
   先生ごとの変更連絡（印刷・PDF）、変更点の一覧。MYreminder とつなげて「自分の授業が変わったら割り込んで知らせる」こともできる。

## 10. 確認したいこと

1. **立場**：学校全体の時間割変更を作る係ですか？ それとも自分の授業の変更が中心ですか？
2. **学校の規模**：クラス数・先生の数・選択授業や展開授業の多さ（だいたいでOK）
3. **使いづらいところ**：特にどの操作・画面ですか？
4. **駒があてはめられなかった場面**：年度はじめの作成のときですか？ 日々の変更のときですか？
5. **機械的な変更でうまくいかなかった例**：ソフトの案をどう直しましたか？ そのとき頭の中で考えていたルールは？
6. **いまの流れ**：変更の依頼はどう受けて（紙・口頭・Teams など）、どう伝えて（掲示・印刷・Teams など）、時数の貸し借りはどう記録していますか（Excel など）？
7. **イデアの版**：標準版ですか？ スクールパックですか？ CSV や Excel で時間割を取り出したことはありますか？
