# MYreminder

**開かなくても、必要な瞬間に向こうから割り込んでくる**リマインダー（職場のWindows PC用）

- 一言書くだけ。授業・帰りST・予定・メモに自動で振り分け
- 授業の5分前・帰りSTの5分前などに、画面の一番前にでかでか出る
- プロジェクタにつながっている時は中身をかくす（目隠しモード）
- 3分さわらなかったら iPhone に「PCにリマインドがあります」と通知（中身は送らない）
- 終わったら ✓ で消える。やり残しは赤く残る
- データはこのPCの中だけに保存

構想は [docs/concept.md](docs/concept.md) にあります。

---

## 入れ方（1回だけ）

1. GitHub のこのリポジトリの **Actions** タブを開く
2. 一番上の「Windows build」（緑のチェックがついたもの）を開く
3. 下のほうの **Artifacts** にある `MYreminder-Setup` をダウンロード
4. ダウンロードした zip を開いて、`MYreminder-Setup-0.1.0.exe` をダブルクリック
5. 「WindowsによってPCが保護されました」と出たら「詳細情報」→「実行」
6. 画面右下のタスクトレイ（`^` の中）に青い「！」が出て、画面の右端に「＋」ボタンが出れば完了

次からは、PCにログインすると自動で起動します。
学校のウイルス対策ソフトなどで止められた場合は、そのときの画面を教えてください。

## 使い方

### 入れる

- **`Ctrl` + `Shift` + `Space`**、または画面の右端の **「＋」** を押すと入力欄が出ます
- 一言書いて `Enter`（または「入れる」）
- 声で入れるなら、入力欄で **`Windowsキー` + `H`**

| こう書くと | ここに入る |
| --- | --- |
| `3-4 プリント配る` | 次の 3-4 の授業 |
| `論表 小テスト返す` | 次の論表の授業 |
| `3限 プリント` | 今日の3限（過ぎていたら次の3限） |
| `帰りST 保護者会の手紙` | 今日の帰りST（過ぎていたら次の日） |
| `朝ST 提出物` | 次の朝ST |
| `進路部で話す` / `学年会で報告` | 次の進路部 / 3年担 |
| `金曜 15時 学年会` | 金曜15時の予定 |
| `明日 鍵返す` | 明日のメモ |
| `鍵返す` | 今日のメモ |

入れたあとに「その次」「帰りST」「今日のメモ」のボタンで入れ先を変えたり、「とりけし」したりできます。

### 割り込んでくるタイミング（用事がある時だけ）

| いつ | 何が出るか |
| --- | --- |
| 朝、その日はじめてPCを触った時 | 今日のまとめ |
| 授業の5分前 | その授業の用事 |
| 昼休みの始め | 今日のメモ・午後の予定 |
| 帰りSTの5分前 | 帰りSTの用事・今日のメモ・やり残し |
| 予定の10分前 | その予定 |

- **わかった**：閉じる（用事は残る）
- **5分後にもう一度**：5分後にまた出る
- **✓**：やった。消える
- やらないまま時間が過ぎた用事は **赤く** なって、次の割り込みのたびに「終わった？」と出ます

### プロジェクタにつないでいる時

割り込みの中身をかくして「📌 3限の用事が2件あります」だけ出します。「タップして表示」で中身が出ます。
最初に一度、プロジェクタをつないだ状態で **設定 → 目隠しモード →「いまの画面を調べる」** を押して、「プロジェクタあり」と出るか確かめてください。

### スマホ通知（iPhone）

**タスクトレイの「！」を右クリック → 設定…** の「スマホ通知」に手順があります。

1. iPhone に「ntfy」アプリを入れる
2. ntfy で「＋」→ 設定画面に出ている文字（`myrem-…`）を入れて Subscribe
3. 設定画面で「スマホ通知を使う」にチェック →「テスト通知を送る」

送るのは「📌 PCにリマインドがあります（3限の前）」のような文だけで、用事の中身は送りません。

### 時間割どおりでない日（テスト・行事など）

タスクトレイの「！」を右クリック →「今日は時間割どおりではない」にチェック。その日は授業の割り込みが止まります。
祝日・土日は自動でとばします。

### 時間割が変わった時

設定 →「設定ファイルを開く」で、メモ帳で書きかえて保存すると、すぐに反映されます。

```json
"timetable": {
  "月": { "3": "論表Ⅲ 3-1", "4": "ECⅢ 3-4", "7": "LT 3-3" },
  ...
}
```

## 開発者向け

```sh
npm install
npm start        # 起動
npm test         # 振り分け・割り込みのテスト
npm run dist     # Windows のインストーラーを作る（Windows 上で）

# 画面の動作確認（Linux、スクリーンショットを撮る）
xvfb-run -a -s "-screen 0 1366x900x24" npx electron --no-sandbox scripts/smoke.js --out=smoke-out
```

| 場所 | 中身 |
| --- | --- |
| `src/core/` | 振り分け（parser）・時間割・祝日・割り込みのタイミング。Electron に依存しない |
| `src/main/` | 常駐・タスクトレイ・割り込み画面・プロジェクタ検知・スマホ通知 |
| `src/renderer/` | 各画面（割り込み・入力・一覧・設定・＋ボタン） |
| `test/` | `src/core` のテスト |

データは `%APPDATA%\MYreminder\`（`data.json`・`settings.json`）に保存されます。
